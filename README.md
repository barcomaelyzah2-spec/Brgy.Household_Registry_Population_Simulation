# Brgy. Household Registry and Population Simulation System

## Project Description

The Brgy. Household Registry and Population Simulation System is a web-based system designed to organize and manage household and resident information in a barangay.

The system allows users to register residents, record household information, assign residents to a Purok, search registered records, and view basic population and household counts. It provides a simple way to organize community records and simulate population information.

## Features

- Resident registration
- Household number recording
- Number of members in each household
- Purok assignment
- Population count
- Household count
- Resident count
- Search functionality
- Residents list
- Registration date tracking
- Record actions for managing resident information

## Technologies Used

- HTML
- CSS
- JavaScript

## Installation / Usage

1. Download or clone this repository.
2. Open the project folder.
3. Open the main HTML file in a web browser.
4. Fill in the resident's information:
   - Full Name
   - House No.
   - Members in House
   - Purok
5. Click the *Register* button to add the record.
6. Use the *Search* field to find registered residents.
7. View the registered records in the *Residents List*.

## System Information

The system displays basic information such as:

- Total Population
- Total Houses
- Total Residents

The registered information is presented in an organized table containing the resident's ID, name, house number, number of members, Purok, date registered, and available actions.
